# Security Policy

## Supported Versions

This project is in active development. Security fixes are applied to the latest code on the default branch.

## Reporting a Vulnerability

Please do **not** open public GitHub issues for suspected security vulnerabilities.

Use **GitHub Private Vulnerability Reporting** (Security Advisories) if it is enabled for this repository.

If private reporting is not available, contact the repository maintainer directly and include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)
